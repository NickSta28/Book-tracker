# Bücher-Tracker

Private Web-App (PWA) zum Erfassen und Auswerten gelesener Bücher. Läuft als statische Seite auf GitHub Pages,
Daten und Logins liegen in Supabase.

- `index.html`, `css/`, `js/` – die App
- `supabase/` – Datenbank-Schema und Abfrage-Dienst für ISBN-Daten (siehe `supabase/README.md`)
- `scan-test/` – Test der Kamera-Erkennung (nicht mehr nötig)
